# System Design

## ผู้ใช้งาน
- ผู้ดูแลระบบ
- หัวหน้ากลุ่มงาน
- ผู้รับผิดชอบงาน
- ผู้ร่วมปฏิบัติงาน
- ผู้ดูรายงาน

## Workflow
1. สร้างภารกิจ/งาน
2. กำหนดผู้รับผิดชอบ
3. กำหนดเป้าหมายและกำหนดส่ง
4. ดำเนินงานและบันทึกความก้าวหน้า
5. แนบหลักฐาน
6. หัวหน้างานติดตาม/ตรวจสอบ
7. ปิดงาน
8. สรุปผลเข้า Dashboard และรายงาน

## สถานะงาน
- ยังไม่เริ่ม
- กำลังดำเนินการ
- รอติดตาม
- เสร็จสิ้น
- เกินกำหนด

## Dashboard
- งานทั้งหมด
- งานกำลังดำเนินการ
- งานใกล้ครบกำหนด
- งานเกินกำหนด
- KPI สำเร็จ/ไม่สำเร็จ
- ผลงานแยกตาม 13 กลุ่มงาน

## ข้อกำหนดด้านข้อมูล
ระบบระยะแรกควรเก็บเฉพาะข้อมูลบริหารงาน ตัวชี้วัด เอกสาร และหลักฐานที่จำเป็น หลีกเลี่ยงข้อมูลระบุตัวผู้ป่วย และกำหนดสิทธิ์การเข้าถึงตามบทบาท
