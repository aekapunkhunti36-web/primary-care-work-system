# ระบบบริหารงานกลุ่มงานบริการด้านปฐมภูมิและองค์รวม

โรงพยาบาลโพนนาแก้ว

## วัตถุประสงค์
ระบบสำหรับวางแผน มอบหมาย ติดตามงาน ตัวชี้วัด เอกสาร และรายงานของกลุ่มงานบริการด้านปฐมภูมิและองค์รวม โดยออกแบบให้ต่อยอดเป็น Web Application ได้

## โมดูลหลัก
1. เวชปฏิบัติครอบครัวและชุมชน
2. การพยาบาลในชุมชน
3. ส่งเสริมสุขภาพทุกกลุ่มวัย
4. ป้องกันและควบคุมโรคและระบาดวิทยา
5. อาชีวอนามัยและความปลอดภัย
6. สุขาภิบาลและอนามัยสิ่งแวดล้อม
7. พัฒนาระบบบริการปฐมภูมิและสนับสนุนเครือข่าย / สุขภาพภาคประชาชน
8. อนามัยโรงเรียน
9. สุขภาพจิตและจิตเวชในชุมชน
10. บำบัดยาเสพติด สุรา บุหรี่ ในชุมชน
11. สุขศึกษาและพัฒนาพฤติกรรมสุขภาพ
12. จัดเก็บรายได้หน่วยบริการ
13. ข้อมูลคุณภาพ

## แนวคิดระบบ
- Dashboard ภาพรวม
- ระบบมอบหมายและติดตามงาน
- ปฏิทินงาน
- KPI และผลการดำเนินงาน
- ระบบรายงาน
- การแนบหลักฐาน
- สิทธิ์ผู้ใช้งานตามบทบาท

> รุ่นแรกเน้นข้อมูลบริหารงานและ KPI และหลีกเลี่ยงการจัดเก็บข้อมูลระบุตัวผู้ป่วยโดยไม่จำเป็น
